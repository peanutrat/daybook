# 日日手帳（免登入版）

月曆蓋章、共用當日清單、可收合的蘑菇計時、筆記資料夾及日／週／月收成回顧。

## 使用與資料保存

開啟 https://qw7009384.github.io/daybook/ 即可使用，不需登入。資料只存在目前網址的瀏覽器 localStorage，每位訪客的紀錄各自獨立；没有雲端同步。設定 → 備份與回收桶 → 下載完整 JSON 備份，可保存手帳、筆記圖片與蘑菇紀錄。舊版備份仍可匯入。本儲存庫不包含任何私人紀錄。

## 計時與筆記

月曆年月旁的計時列可展開／收合；清單按 ▶ 開始計時時保留收合狀態。完成 » 結束記錄並勾選連結待辦，採收可選擇立即或稍後。補記時間可直接選取當日待辦或自行輸入名稱。

筆記支援視覺編輯或手打語法：粗體、斜體、小標題、縮小文字、刪除線、防雷海苔、連結、字色及字級。可展開長文、複製純文字或匯出 TXT／PNG；PNG 包含附圖。圖片匯入後可直接拖曳裁切，儲存時替換同一張圖片。

## GitHub Pages

Settings → Pages 選 Deploy from a branch，分支 main、資料夾 /docs。docs 包含建置結果。修改原始碼後執行 npm install、npm run build，將 dist 內容同步至 docs。
