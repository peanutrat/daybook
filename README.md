# 日日手帳（免登入版）

日曆蓋章、每日與一次性待辦、短筆記、塗鴉畫布、主題與夜間模式，以及 PNG 匯出。

## 資料儲存

資料只存在同一網址的目前瀏覽器 localStorage，各訪客獨立，沒有帳號或雲端同步。清除網站資料會移除紀錄。請使用設定 → 備份與回收桶 → 下載完整 JSON 備份。

原私人網站紀錄可先匯出 JSON，再在這裡匯入。此程式不包含任何私人手帳紀錄。

## GitHub Pages

將此資料夾內容（包含 docs 與 src）上傳到儲存庫。在 Settings → Pages 選 Deploy from a branch，分支 main，資料夾 /docs，儲存即可。

docs 已含建置好的檔案，首次發布不需安裝。後續修改程式請執行 npm install、npm run build，將 dist 內容更新到 docs。

## 蘑菇計時與收成

月曆內有可收合的計時區塊，可從當日待辦開始正計時，也能自由記錄、暫停或補記時間。時間會累積成樹樁上的蘑菇；收成回顧可查看每日、每週、每月的統計並匯出圖片。完整 JSON 備份包含蘑菇紀錄。

## 塗鴉畫布

可新建透明畫布或匯入圖片，使用筆刷、橡皮擦、選取、圖層與影像調整功能。底紙可切換點點紙、方格紙、白紙或自訂底色，並選擇匯出時是否包含底紙。電腦與手機保留各自的工具配置；工具可移動、收合、合併並鎖定，也能儲存及匯出工作區。

電腦版預設工具位置依使用者提供的工作區配置。已有自訂配置者，可從塗鴉設定 → 工具列與工具顯示 → 恢復預設工具配置套用。
