# 我的收成冊：翻頁手札

## 結構與相容性

原本蘑菇統計由獨立 iframe 的 `bookData`、`activityRows`、`mushroomGroups` 與 `weekSummary` 計算；喝水統計由 React 的 `waterPeriod` 計算。這次保留兩套既有資料來源，用唯讀投影接入同一個閱讀介面。沒有遷移、刪除或改寫紀錄，也沒有移除像素素材。

蘑菇引擎維持掛載，計時器與原本的儲存、採收、備份流程不變。在收成冊中，原本完整結算留在畫面外作為圖片匯出來源；閱讀畫面只取得統計投影。訊息檢查相同來源與 iframe 身分。切換日期／週期後只接受相符的統計，避免舊報表被誤匯出。

## 功能

- 蘑菇／旅程頁籤共用日、週、月與日期控制。分類、日期、週期改變後回到第一頁。
- 桌面雙頁，手機單頁；依實際可用寬度同步切換版面及分頁容量。書頁高度限制在 560–590px，內容不設巢狀捲動。
- 蘑菇第一頁總覽，之後為原素材收藏頁、活動紀錄頁。容量依書頁高度調整；空紀錄只有總覽，不建立空收藏頁。
- 旅程第一頁總覽，之後為分頁的每日統計、風景票根與補水明細。保留風景選擇和每日票根匯出。
- 上下頁按鈕、頁碼、直接跳頁；桌面另有側邊週期頁籤。頁籤支援左右方向鍵。
- 沿用繁中／英文介面。旅程頁型可繼續擴充，本次沒有新增地圖生成、事件或收藏系統。

## 圖片匯出

蘑菇日／月沿用原 Canvas 結算，週沿用原完整 DOM 快照，與正在閱讀的頁碼無關。原有配色、素材、數據與樣式保留。

旅程原有每日風景票根保持 1200×900 的原繪圖流程。另提供選定日／週／月的完整飲水明細圖片；過長時每 180 行分成有編號的 PNG，放入一個 ZIP，避免單張圖片超過瀏覽器尺寸限制。此功能不取代原票根匯出。

## 驗證

- TypeScript 編譯檢查、正式建置。
- 純資料測試：137 筆活動、30 種蘑菇、251 筆飲水，在 320／390／760／1100px 分頁，不重複、不遺漏、總計一致，原 JSON 不變。
- 匯出測試：251 筆明細全部進入繪圖流程，分成兩張 PNG，ZIP 通過 `unzip -t`。這項測試以 Canvas stub 檢查內容覆蓋；實際繪圖另由瀏覽器驗證。
- 原有 `water-review` 測試：跨週、跨月、跨年、閏年、補零日期、風景選擇保存。
- 原有 `water-trip-ui` 測試：繁中與英文的飲水、預設杯量、目標計算和小精靈設定。
- Chrome 實際操作：桌面雙頁、390px 單頁、分類／日週月／日期／直接跳頁、零紀錄提示、英文介面。總覽、蘑菇收藏、活動、圖表與票根頁沒有內容溢出；手機書頁沒有水平捲動。
- 實際下載：64 筆活動／30 種蘑菇的每日結算為 760×7338 PNG；週結算為 760×1300 PNG；70 筆飲水完整結算及 1200×900 風景票根均成功產生。測試資料完成後已還原，暫時 QA 頁不包含於發佈內容。

限制：本次以 Chrome 桌面及 390px 響應式視窗驗證，沒有真機 Safari 測試。原有蘑菇超長單張圖片仍受瀏覽器 Canvas 上限限制；此次保留其原匯出格式。
